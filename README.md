# Portfólio de Fotografia (React + TypeScript)

Aplicação web para portfólio fotográfico com:

- Galeria responsiva
- Filtro por categorias
- Clique na foto para ampliar em modal

## Executar localmente

```bash
cd photo_portfolio_react
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```
